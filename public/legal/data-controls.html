Data controls

You should be able to see, edit, pause, and delete what Goalden knows.

The point of Goalden is accountability, not hidden surveillance. The product should keep tasks, sources, and blocking rules understandable and removable.

Review extracted tasks

Tasks found from chats should appear in a review queue before they become recurring blockers. You should be able to edit or dismiss a task when the AI gets it wrong.

Pause a source

You should be able to pause Slack, Notion, Telegram, WhatsApp, email, or docs without disabling the full extension.

Delete local history

Local settings, active timers, progress reports, and cached tasks should be removable from the browser.

Change block rules

You should be able to choose which sites Goalden blocks, how long breaks last, and which task appears in the blocking prompt.

Expected controls

See connected sourcesA simple list of every connected workspace, chat, or document source.
Disconnect a sourceStopping future reads should be available from the product UI.
Clear browser dataThe extension should expose a clear path for resetting local Goalden state.
Ask for manual helpWhile Goalden is in beta, deletion or account requests can be handled through the Gmail contact in the footer.
